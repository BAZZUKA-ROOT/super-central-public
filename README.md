# Super Central — Public App

Public ChatGPT MCP preview. This package has no local file access or PC control.

- GET / : homepage
- GET /health : health
- GET /privacy : privacy policy
- GET /terms : terms
- GET /support : support page (contact pending)
- GET /.well-known/openai-apps-challenge : verification token from environment
- /mcp : Streamable HTTP MCP with read-only tools

Start locally: python -m pip install -r requirements.txt && python app.py

The main desktop service at D:\SUPER_INTELIGENCIA\agente\central-mcp is NOT part of this cloud repository. Do not add or upload desktop credentials or catalog snapshots.
